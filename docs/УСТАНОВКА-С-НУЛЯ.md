# Установка с нуля: ZCODE Control (ПК с Windows + телефон)

От «ничего нет» до управления ZCODE с телефона — примерно 20 минут.

**Что понадобится:** компьютер с Windows и ZCode, телефон с Telegram, 15 минут.

---

## Шаг 1. Установить Node.js (один раз)

1. Откройте https://nodejs.org → скачайте **LTS** (22 или новее).
2. Установите, ничего не меняя в галочках (важно: «Add to PATH» отмечено по умолчанию).
3. Проверка: откройте PowerShell (Пуск → напишите «powershell») и введите:
   ```
   node -v
   ```
   Должно показать версию, например `v24.14.1`. Если «не является командой» — переустановите Node и **перезапустите PowerShell**.

## Шаг 2. Скачать проект (один раз)

1. Откройте https://github.com/ivan-cruzzz/zcode-control
2. Зелёная кнопка **Code** → **Download ZIP**.
3. Распакуйте архив, например в `C:\Users\<вы>\Desktop\zcode-control`.
   (Если стоит git — можно вместо этого: `git clone https://github.com/ivan-cruzzz/zcode-control.git`)

Дальше всё делаем в папке **zcode-control\server** этого проекта.

## Шаг 3. Получить токен бота у @BotFather (один раз)

1. В Telegram найдите **@BotFather** → кнопка **Start**.
2. Напишите `/newbot` → придумайте имя (например, `My ZCODE`) → придумайте username (должен кончаться на `bot`, например `ваш_бот`).
3. BotFather пришлёт **токен** вида:
   ```
   1234567890:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   Скопируйте его целиком. **Никому не показывайте** — это ключ управления ботом.
4. (Уже есть бот?) → `/mybots` → выберите бота → **API Token** → «Copy».

## Шаг 4. Настроить мост (один раз)

Ничего создавать руками не нужно — мост сам спросит токен при первом запуске.

1. Откройте терминал в папке `server` (правый клик по пустому месту → «Открыть в терминале»).
2. Выполните:
   ```
   npm install
   ```
   Должно закончиться словами «added … packages».
3. Выполните:
   ```
   npm start
   ```
4. Мост сам напишет «Первый запуск: нужна настройка» и попросит вставить токен. **Вставьте токен из Шага 3 и нажмите Enter** — файл настроек создастся сам, и мост продолжит запуск.

## Шаг 5. Запустить мост

В том же терминале:
```
npm start
```
**Вы должны увидеть три строки** (цифры и адрес будут другими):
```
мост запущен: режим=zcode, порт=8787
туннель: https://что-нибудь.trycloudflare.com
кнопка меню бота обновлена (адрес туннеля внутри)
```
**Это окно — связь с телефоном. Не закрывайте его.** Первый запуск скачает `cloudflared` в `server\bin\` (это нормально).

> Ошибка `EADDRINUSE`? Мост уже работает в другом окне — закройте то окно или введите `set PORT=8788 && npm start`.
> Ошибка про базу ZCODE? Запускайте на ПК, где установлен ZCode (мост читает его базу только для чтения).

## Шаг 6. Подключить телефон (10 секунд)

1. В Telegram откройте **своего бота** (найдите по username, который придумали в Шаге 3) → **Start**.
2. Нажмите **кнопку меню** (синий квадратик слева от поля ввода) — или `/start` → кнопку в сообщении «Открыть ZCODE Control».
3. Приложение откроется **подключённым**: вверху «на связи», на Обзоре — данные с вашего ПК.
4. Если появится «Закрепить этот аккаунт за мостом» — нажмите один раз. Теперь мост отвечает только вашему Telegram-аккаунту.

## Шаг 7. Привязать бота к ZCODE (чтобы командовать через чат)

1. Откройте **ZCode на ПК** → панель **Bots** → **+ New bot**.
2. Вставьте туда **тот же токен** из Шага 3.
3. Включите переключатель — появится «Telegram long polling is running».
4. В мини-аппе: вкладка **Обзор** → чек-лист «Подключение ZCODE» — все пункты зелёные. Если «поллинг» серый — включите бота тумблером во вкладке **Боты**.

Готово: **пишите боту в чат текстом** («сделай…», «покажи статус») — ZCODE выполняет на компьютере.

## Шаг 8. Ежедневное использование

| Хочу… | Где |
|---|---|
| Дать задание ZCODE | Чат бота в Telegram, обычным текстом |
| Видеть, что происходит | Мини-апп → **Обзор** (статус, токены, график) |
| Читать сессии и искать | **Сессии** (внутри — задачи, диалог, инструменты, поиск) |
| Спросить «что делает ZCODE?» | **Чат** — обычными словами |
| Настроить бота (ответы, проекты, команды) | **Боты** |
| Подписка Pro (без лимита туннеля) | `/sub` в чате бота, ⭐ 100 звёзд / 30 дней |

**Каждый раз при включении ПК:** открыть терминал в `server` → `npm start` → тапнуть свежую кнопку в боте (адрес туннеля обновляется сам).
**Автозапуск:** Win+R → `shell:startup` → положите ярлык на `npm start` из папки `server`.

## Если что-то не работает

| Симптом | Решение |
|---|---|
| «демо» и @demo_helper_bot в приложении | Мост не запущен → Шаг 5, потом откройте приложение через кнопку меню |
| `EADDRINUSE :8787` | Мост уже работает в другом окне — закройте его |
| «нет связи» при работающем мосте | Переоткройте приложение через кнопку меню (адрес туннеля обновился) |
| «закреплён за другим аккаунтом» | Удалите `server\.owner.json`, перезапустите мост |
| Бот молчит на /status | Убедитесь, что в `.env` токен именно этого бота; перезапустите мост |
| Туннель закрылся сам | Прошло 8 ч бесплатного лимита → перезапуск моста или Pro |
| Мост пишет «конфликт 409» | Ботом уже управляет ZCode — всё нормально, пульт работает |

## Безопасность — что важно знать

- Токен бота лежит **только** в `server\.env` на вашем ПК (в git не попадает).
- Мост отвечает **только вашему аккаунту** (пейринг владельца, Шаг 6.4).
- Мост читает базу ZCODE **только для чтения** — работе ZCODE не мешает.
- Токены ботов внутри ZCode зашифрованы самим ZCode; мост их не видит.
