# Полная инструкция: подключить ZCODE к мини-аппу и управлять им с телефона

Для обычного человека: никакой консоли открывать не нужно, кроме одного шага с командой запуска.

---

## Часть 1. Запустить мост на компьютере (один раз перед работой)

Мост — это маленькая программа на вашем ПК, которая соединяет ZCODE с телефоном.

1. Откройте папку `папка проекта\Desktop\tgC\server`.
2. Щёлкните по пустому месту правой кнопкой → «Открыть в терминале» (или откройте PowerShell и введите `cd папка проекта\Desktop\tgC\server`).
3. Введите команду:
   ```
   npm start
   ```
4. Увидите строки: `мост запущен`, `туннель: https://…trycloudflare.com`, `кнопка меню бота обновлена`. **Окно не закрывайте** — пока оно открыто, телефон видит ваш компьютер.

> Если пишет «npm не является командой» — установите Node.js с nodejs.org (версия 22 или новее) и повторите.
> Если пишет «cloudflared не найден» — файл уже лежит в `server\bin\`, эта ошибка означает, что вы запустили из другой папки.

**Автозапуск (по желанию):** нажмите Win+R → `shell:startup` → положите туда ярлык, который запускает `npm start` из папки `server`. Тогда мост будет стартовать сам при включении ПК.

## Часть 2. Подключить телефон (10 секунд)

1. Откройте в Telegram бота **@ваш_бот**.
2. Нажмите **кнопку меню внизу чата** (синий квадратик слева от поля ввода) — или отправьте `/start` и нажмите кнопку в сообщении.
3. Мини-апп откроется **уже подключённым**: вверху будет «на связи», а на Обзоре — ваши настоящие сессии ZCODE.
4. Если появится баннер «Закрепить этот аккаунт за мостом» — нажмите один раз. Это защита: после неё мост будет отвечать только вашему Telegram-аккаунту.

> Адрес туннеля меняется при каждом перезапуске моста — не страшно: мост сам обновляет кнопку меню, просто всегда открывайте приложение через неё.

## Часть 3. Привязать бота к ZCODE (чтобы команды работали)

Сейчас мини-апп **видит** ZCODE. Чтобы **командовать** ему через чат бота, бот должен быть «внутри» ZCode:

1. Откройте **ZCode на компьютере** → панель **Bots** → **+ New bot**.
2. Получите токен: в Telegram откройте **@BotFather** → отправьте `/mybots` → выберите **@ваш_бот** → **API Token** → скопируйте токен (вида `1234567890:AA…`).
3. Вставьте токен в поле нового бота в ZCode и **включите переключатель**. Должна появиться надпись «Telegram long polling is running».
4. Вернитесь в мини-апп → вкладка **Обзор** → в чек-листе «Подключение ZCODE» все пункты должны стать с галочками. Если бот привязан, но выключен — включите его тумблером во вкладке **Боты**.

> ⚠️ Важно: после привязки бот в Telegram обслуживается самим ZCode. Наш мост это понимает и уступает ему опрос автоматически — ничего делать не нужно.

## Часть 4. Как управлять ZCODE с телефона

**Через чат бота (главный способ командовать):**
- просто пишите боту задания текстом: «сделай…», «проверь…», «покажи статус» — ZCODE выполнит на компьютере;
- команды: `/status`, `/new`, смена модели и режима — настраиваются во вкладке **Боты** (какие разрешить).

**Через мини-апп (панель наблюдения и управления):**
- **Обзор** — живой статус, активная сессия, токены за день, график за неделю, мастер подключения;
- **Сессии** — список всех сессий ZCODE; внутри карточки: задачи, диалог с ассистентом, инструменты; поиск по всем сообщениям;
- **Консоль** — команды пульта со slash-меню: `/status`, `/sessions`, `/bots`, `/stats`, `/setup`, `/goto`, `/theme`, `/clear` (выбор модели Z.ai — GLM-5.3 / GLM-4.6 / GLM-5.3-Flash);
- **Боты** — включение/выключение, гранулярность ответов, доступ к проектам, разрешённые команды, удаление;
- **Настройки** — адрес моста, владелец, тема, вибрация.

**Про подписку:** бесплатно туннель работает 8 часов после каждого запуска моста. Подписка **Pro** (⭐ 100 звёзд за 30 дней, команда `/sub` в чате бота) снимает лимит.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| В приложении «демо» и @demo_helper_bot | Мост не запущен → Часть 1, затем откройте приложение заново через кнопку меню |
| «нет связи» при запущенном мосте | Туннель перезапустился → закройте и снова откройте приложение через кнопку меню бота |
| «Мост закреплён за другим аккаунтом» | Мост уже привязан к другому Telegram → на ПК удалите файл `server\.owner.json` и перезапустите мост |
| Инвойс не приходит | Подписка отправляется командой `/sub` в чате бота; для оплаты нужны Telegram Stars (пополнить можно в настройках Telegram) |
| «доступ только для владельца» | Так и задумано: отвечает только ваш аккаунт |
| Мост пишет «конфликт 409» | Бот сейчас обслуживается ZCode — это нормально, пульт продолжает работать |
| Туннель закрылся сам | Истёк бесплатный лимит (8 ч) → перезапустите мост или оформите Pro |
