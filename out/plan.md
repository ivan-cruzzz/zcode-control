# План дизайна: ZCODE Control v2 (Telegram Mini App)

Источник правды: `Desktop/дизайн/минимализм/miniDESIGN.md` (компоненты ai-prompt-box,
floating-dock, flow-button, line-chart) + apple-design (HIG). Исходного видео нет —
все [D] строки привязаны к секциям miniDESIGN с конкретными длительностями.

## Глобальная рамка

[S1] Фон страницы: светлая тема #FFFFFF, тёмная #1F2023; текст #111111 / #F3F4F6; контраст ≥ 4.5:1.
[S2] Шрифт Inter, tracking -0.01em у body; заголовки 600, -0.02em; mono — только цифры/коды.
[S3] Радиусы: кнопки/чипы 8–12px, карточки 16px, поверхности (prompt box) 24px, pill 9999px.
[S4] Разделение слоёв границей 1px #ECECEE (светлая) / #444444 (тёмная); тени только у плавающих элементов (dock, prompt box).
[S5] Смысловые акценты: инфо #1EAEDB, ИИ #8B5CF6, предупреждение #F97316, опасность #EF4444; активный режим = bg accent/15% + border accent + text accent, не сплошная заливка.
[S6] Навигация — плавающий док внизу: fixed, по центру, стекло rgba(255,255,255,.8)/blur 24px (тёмная: rgba(31,32,35,.8)), радиус 16px, тень 0 20px 48px rgba(0,0,0,.105); пункты 48×48, радиус 12px, иконки 20px; активный — синий #2563EB + точка 4px снизу; не более 5 пунктов; safe-area снизу ≥ 12px.
[S7] Отступы по шкале 4px: внутри компонентов 12–16px; карточки в списке с шагом 8px.

## Экран «Консоль» (AI Prompt Box, miniDESIGN §3.3)

[S8] Контейнер ввода: радиус 24px, фон #1F2023 (обе темы — тёмный «фокус» на светлой странице), граница 1px #444444, паддинг 8px, тень 0 8px 30px rgba(0,0,0,.24), липнет к низу контента.
[S9] Textarea прозрачный, 16px, текст #F3F4F6, placeholder #9CA3AF; Enter — отправка, Shift+Enter — перенос строки.
[S10] Кнопка отправки справа: круг 32px; пусто — ghost-иконка; есть текст — белая с чёрной стрелкой вверх.
[S11] Чипы быстрых команд над полем: pill 32px, моно 12px; активная команда — bg accent/15% + border accent + text accent.
[S12] Лента ответов: пузырь пользователя — белый #FFFFFF текст #111 на тёмной ленте; ответ ассистента — #2E3033 с границей #333, радиус 16px; моно-метка времени 11px #9CA3AF.

## Динамика (без исходного видео — тайминги из miniDESIGN §2.7)

[D1] Появление ленты/карточек: 240ms, cubic-bezier(.22,1,.36,1), transform+opacity (miniDESIGN §2.7 standard).
[D2] Раскрытие лейбла чипа команды: 200ms из width:0 (miniDESIGN §3.3 режимы).
[D3] Смена активного чипа/дока: 160ms fast (miniDESIGN §2.7).
[D4] Отрисовка линии графика слева-направо ≈ 840ms при первом появлении (miniDESIGN §3.4).
[D5] prefers-reduced-motion: все анимации мгновенные (miniDESIGN §2.7 + HIG).
