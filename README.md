## Что это

Две части, которые вместе дают полный контроль над ZCode со смартфона:

- **Мини-апп** — Telegram Mini App (статика на GitHub Pages): живой статус, сессии с диалогами и задачами, поиск, чат-ассистент, статистика токенов, управление ботами.
- **Мост** — маленький Node-сервер, который запускается на вашем ПК рядом с ZCode. Читает базу ZCode **только для чтения**, поднимает HTTPS-туннель автоматически и проверяет, что данные получает только владелец.

Никакого облака с вашими данными: переписка и статистика не покидают ваш компьютер — мини-апп забирает их через защищённый туннель.

## Возможности

| Экран | Что умеет |
|---|---|
| **Обзор** | Живой статус ZCode (активен/простаивает), текущая сессия, модель и режим, токены за день, график за 7 дней, лента активности, мастер подключения с чек-листом |
| **Сессии** | Все сессии с метками `live`/`готово`/`прервана`; внутри — задачи (todo), диалог с ассистентом, использованные инструменты; полнотекстовый поиск по всем сообщениям; отправка текста в сессию |
| **Чат** | Диалоговый пульт: спрашивайте обычными словами — «что делает ZCODE?», «какие задачи?», «найди …»; slash-команды; выбор моделей Z.ai (GLM-5.3 / GLM-4.6 / GLM-5.3-Flash) |
| **Боты** | Управление ботами ZCode с телефона: вкл/выкл, гранулярность ответов, доступ к проектам, разрешённые команды, переименование, удаление, статус поллинга |
| **Статистика** | Токены по дням, топ моделей и инструментов |

## Архитектура

```
┌──────────────┐  HTTPS/WSS   ┌───────────────────┐  read-only   ┌────────────────┐
│   Telegram    │ ───────────▶ │  Локальный мост    │ ───────────▶ │  База ZCode     │
│   Mini App    │  JSON + WS   │  (server/, ваш ПК) │    SQLite    │  db.sqlite      │
│  (GitHub      │ ◀─────────── │  проверка подписи  │              │  session, todo, │
│   Pages)      │ live-события │  initData HMAC     │              │  message, usage │
└──────────────┘              └───────────────────┘              └────────────────┘
        │                              │
        │  кнопка меню бота несёт      │  автотуннель cloudflared
        └── свежий адрес туннеля ◀─────┘  (поднимается сам при старте)
```

- Статика мини-аппа публикуется на GitHub Pages — серверной части в облаке нет.
- Мост при старте сам поднимает cloudflared quick-туннель и **обновляет кнопку меню бота**, чтобы приложение всегда открывалось с актуальным адресом.
- Живые обновления — WebSocket; при его недоступности клиент переходит на опрос.
- Отправка сообщений в ZCode идёт через **чат бота** (штатный механизм ZCode): мини-апп готовит текст, ZCode выполняет — переписка появляется в приложении автоматически.

## Безопасность

| Где | Что | Почему безопасно |
|---|---|---|
| `server/.env` | токен бота, ключи MTProto | В `.gitignore`, существует только на вашем ПК |
| Мини-апп | ничего | Авторизация — подписанный Telegram `initData` |
| Репозиторий | ничего | CI публикует только статику `app/dist` |
| `server/.owner.json` | ваш Telegram id | Пейринг владельца: мост отвечает только вам |
| `credentials` ZCode | токены ботов | Зашифрованы самим ZCode (`enc:v1`); мост их не читает |

- **Пейринг владельца**: при первом входе нажмите «Закрепить этот аккаунт» — дальше мост игнорирует всех остальных (403), даже с валидной подписью.
- **Подпись initData** проверяется HMAC-SHA256 (поддержаны оба формата Telegram) + контроль свежести.
- CORS-allowlist, rate-limit, ограничение размера запроса, `timingSafeEqual`.
- База ZCode открывается **только для чтения**.

## Установка с нуля

Полная пошаговая инструкция для обычного человека — в [docs/УСТАНОВКА-С-НУЛЯ.md](docs/УСТАНОВКА-С-НУЛЯ.md). Коротко:

```bash
# 1. Node.js 22+ с nodejs.org, затем:
git clone https://github.com/ivan-cruzzz/zcode-control.git
cd zcode-control/server

# 2. Токен бота от @BotFather → /newbot (или /mybots → API Token)
npm install
npm start          # мост сам спросит токен и создаст .env

# 3. (опционально, для отправки из мини-аппа от вашего имени)
npm run user       # одноразовый вход Telegram-аккаунта (MTProto)
```

Мост сам поднимет туннель. Затем: откройте бота в Telegram → кнопка меню → мини-апп подключён → «Закрепить этот аккаунт за мостом».

> **Туннель**: bridge сам запускает `cloudflared` (положите бинарник в `server/bin/cloudflared.exe` или `winget install Cloudflare.cloudflared`). Бесплатный quick-туннель живёт 8 часов; подписка Pro снимает лимит. Свой туннель — `--no-expose` + адрес в Настройках приложения.

## Подключение ZCode (команды через чат)

Чтобы **писать ZCode** (а не только видеть), привяжите бота к ZCode — один раз:

1. **ZCode на ПК** → панель **Bots** → **+ New bot**.
2. Токен: **@BotFather** → `/mybots` → ваш бот → **API Token**.
3. Вставьте токен в ZCode, включите — появится «Telegram long polling is running».
4. В мини-аппе: **Обзор** → чек-лист станет зелёным; тумблеры и настройки бота — во вкладке **Боты**.

После этого сообщения боту в Telegram ZCode принимает как задания, а мини-апп показывает ход работы в реальном времени. При привязке мост автоматически уступает опрос бота (конфликт 409 обрабатывается) — туннель и панель продолжают работать.

## Как пользоваться

- **Чат бота** — задания ZCODE обычным текстом: «сделай…», «покажи статус».
- **Обзор / Сессии / Чат / Боты / Настройки** — панель: мониторинг, диалоги, поиск, ассистент, управление.
- **Чат-ассистент** понимает обычные вопросы: «что делает ZCODE?», «какие задачи?», «сколько токенов?», «найди <слово>».

## Настройки моста

Все переменные — в `server/.env` (создаётся автоматически при первом запуске; шаблон — `.env.example`):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — (обязателен) | токен бота от @BotFather |
| `ALLOWED_USER_IDS` | пусто | белый список Telegram id (рекомендуется вместе с пейрингом) |
| `PORT` | `8787` | порт моста |
| `MAX_AUTH_AGE` | `86400` | срок жизни initData, сек |
| `ALLOWED_ORIGINS` | Pages + localhost | CORS для мини-аппа |
| `RATE_LIMIT` | `120` | запросов в минуту с одного IP |
| `ZCODE_DB` | `~/.zcode/cli/db/db.sqlite` | путь к базе ZCode |
| `USER_API_ID` / `USER_API_HASH` | — | ключи MTProto (заполняет `npm run user`) |
| `CLOUDFLARED_PATH` | авто | путь к cloudflared, если не в PATH |
| `EXPOSE` | `1` | `0`/флаг `--no-expose` — отключить автотуннель |

## Оплата

Бесплатно туннель работает **8 часов** после каждого запуска моста. `/sub` в чате бота оформляет **Pro** (⭐ 100 Telegram Stars / 30 дней) — без лимита времени; оплата и продление полностью автоматические.

## API моста

Все методы принимают `{initData, …}` и отвечают `{ok, …}`; время — epoch-миллисекунды.

| Метод | Тело | Ответ |
|---|---|---|
| `POST /api/auth` | `{initData}` | `{ok, user, mode, paired, pairing, ownerMatch}` |
| `POST /api/pair` | `{initData}` | `{ok, paired}` — закрепление владельца |
| `POST /api/overview` | `{initData}` | `{ok, status, stats, activity}` |
| `POST /api/sessions` | `{initData, limit}` | `{ok, sessions}` |
| `POST /api/session` | `{initData, id}` | `{ok, session, todos, messages, tools}` |
| `POST /api/search` | `{initData, q, limit}` | `{ok, results}` |
| `POST /api/stats` | `{initData, days}` | `{ok, daily, models, tools}` |
| `POST /api/bots` | `{initData}` | `{ok, bots, polling}` |
| `POST /api/bot/update` | `{initData, id, patch}` | `{ok, updated}` |
| `POST /api/bot/delete` | `{initData, id}` | `{ok, deleted}` |
| `POST /api/bot/link` | `{initData, token}` | `{ok, verified, username, alreadyLinked}` |
| `POST /api/projects` | `{initData}` | `{ok, projects}` |
| `POST /api/setup` | `{initData}` | `{ok, bridge, ownerPaired, bot, tunnel, billing}` |
| `GET /health` | — | `{ok, mode, tunnel}` |
| `WS /ws` | `{type:"auth", initData}` | `{type:"auth_ok"}` + `{type:"refresh", scope, id?}` |

`replyMode` бота: `assistant_changes` · `assistant_toolcalls_changes` · `summary_changes` · `streaming_card`. Референсная реализация — `server/adapter-zcode.mjs`.

## Деплой

CI собирает мини-апп и публикует на GitHub Pages при каждом push в `main`. Для своего форка: **Settings → Pages → Source: GitHub Actions**; затем добавьте адрес вашего Pages-сайта в `ALLOWED_ORIGINS` моста и (по желанию) обновите кнопку меню бота через `setChatMenuButton`.

## FAQ

**Приложение показывает «демо».** Мост не запущен или адрес не сохранён: Шаг 5 из [инструкции](docs/УСТАНОВКА-С-НУЛЯ.md), затем откройте приложение через кнопку меню бота.

**«Нет связи» при работающем мосте.** Туннель перезапустился и адрес обновился — переоткройте приложение через кнопку меню бота (мост сам обновляет кнопку при каждом старте).

**«Доступ только для владельца» / «закреплён за другим аккаунтом».** Сработал пейринг. Сброс: удалить `server/.owner.json` и перезапустить мост.

**Почему мини-апп не может писать в ZCode напрямую?** ZCode принимает задания только как сообщения вашего аккаунта в Telegram (это его штатный защищённый механизм; внешнего API у него нет). Поэтому: чат бота — для команд, мини-апп — для наблюдения, управления ботами и настроек. Опционально `npm run user` включает отправку из мини-аппа от вашего имени.

**Куда делись туннели без ограничений?** Бесплатно — 8 часов на запуск моста; **Pro** (`/sub`, Telegram Stars) снимает лимит.
